# BioValor AI

## Project Name

BioValor AI

## Description

A Streamlit-based Generative AI decision-support system for identifying potential biological waste valorization pathways.

## Technology Stack

- Python
- Streamlit
- Pandas
- Generative AI
- CSV knowledge base

## Current Status

Phase 1 — Project Setup

## Environment Setup

### Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run the Application

Start the application with:

```bash
streamlit run app.py
```

The Phase 1 application runs without an API key.
